# Jewelry Classify
Notebbook jewelry classify

# Resumen
El objetivo de este proyecto es desarrollar un sistema que aplique técnicas de aprendizaje automático y algoritmos de visión por computador para la identificación de joyas que facilite la clasificación de artículos de joyería.

# Estructura
- 00_documentacion: Carpeta para documentar el proceso, la arquitectura y el análisis y presentación de resultados.
- 01_fase_entrenamiento: Carpeta que aloja los recursos para llevar a acabo el entrenamiento de redes neuronales que genereren modelos de clasificación de artículos de joyería.
- 02_fase_inferencia: Carpeta que aloja los componentes para utilizar los modelos de clasificación entrenados.
